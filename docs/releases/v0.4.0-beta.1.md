# 每天3分钟 / Daily 3 Minutes v0.4.0-beta.1

**测试版 / Pre-release. Google Tasks 真实接入尚未开放 / Live Google Tasks connection is not yet available.**

## 下载安装 / Download and install

- `daily-3-minutes-0.4.0-beta.1.apk`：签名、压缩、非Debug安装包。Android 8.0以上；Android 13以上使用新私有签名并保留旧签名升级链。
  Signed, minified, non-Debug APK for Android 8+. Android 13+ uses the new private signer with an upgrade lineage.
- `daily-3-minutes-0.4.0-beta.1-source.zip`：本版已审计源码、构建脚本和合成测试；不包含密钥或个人记录。
  Audited source, build scripts and synthetic tests for this version, without private keys or personal entries.
- `SHA256SUMS.txt`：分别核对APK和源码ZIP。发行页自动生成的Source code也是源码，不是可安装APK。
  Verify the APK and source ZIP separately. GitHub's automatic Source code archives are not installable APKs.

保留数据时覆盖安装，勿卸载旧版。正式版尚未宣布，历史Debug包不作为正式版下载入口。
Upgrade in place to retain data. A stable release has not been announced; historical Debug packages are not official releases.

## 本版更新 / Changes

- 保留今日编辑、历史三横菜单、月历和近七天交接、上滑收起日历、上下双栏桌面组件。
  Preserves today's editor, history ranges menu, calendar and seven-day handoffs, collapsible calendar and two-panel widget.
- 新增简体中文、英文和跟随系统选项；用户答案不被翻译。
  Adds Simplified Chinese, English and system language choices without translating journal answers.
- 备份导出前保存，成功后记录数量与时间；保留JSON schemaVersion 1、导入预览、默认跳过冲突和事务回滚。
  Saves before export and records the count/time after success. Keeps JSON schemaVersion 1, import preview, conflict skipping and transaction rollback.
- 实现可选Google Tasks交接同步、离线队列、双向冲突保留及数据库v1→v2迁移。
  Implements optional Google Tasks handoff sync, offline queues, two-way conflicts and the v1→v2 database migration.
- **本APK尚未配置Google客户端，连接按钮禁用并解释原因。本地记录、历史、组件和文件备份可用。**
  **This APK has no Google client configured. The connection button is disabled with an explanation. Local journaling, history, widgets and file backup remain available.**
- 中文英文首页栏目对应；区分实际依赖、改编代码、体验参考与Google服务，保留MIT上游及Apache-2.0许可。
  Matched Chinese/English documentation distinguishes dependencies, adapted code, product references and Google services, retaining MIT upstream and Apache-2.0 notices.
