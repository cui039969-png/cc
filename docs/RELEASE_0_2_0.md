# 0.2.0 更新说明

本次按用户要求继续更新，并通过已连接的 GitHub 比较六个公开项目。固定提交、实际阅读路径、许可和取舍见 [开源调研](OPEN_SOURCE_REVIEW.md)。

## 可见变化

- 今日“上次交接”中的长目标可展开/收起，可直接查看来源日期的记录；跳转前先提交当天编辑。
- 搜索卡片标明命中的是“学会了”“还没弄懂”还是“明日优先”，围绕命中位置展示摘要并高亮关键字。数千字前文、连续换行、Emoji 和 `%`、`_` 等字面符号均纳入回归。
- 宽度至少600dp的横屏使用侧边导航，给输入和日历留出更多垂直空间。窄竖屏继续底部导航。
- 前台补充本地日期检查，处理系统广播被写入/备份操作推迟的情况；本月日历随月份变化，主动浏览的历史月份和历史编辑日期保持原选择。
- 设置显示实际构建版本、这次更新及可展开的开源来源列表，点击项目由浏览器打开 GitHub。

## 升级约定

versionCode=2，versionName=0.2.0；沿用 io.github.daily3minutes、同一 Debug 签名及 Room/JSON schema1。
使用覆盖安装，不通过卸载升级。没有 schema 变化，不需要也不虚构一次数据库迁移。
旧0.1.0 APK与源码包保留于本机交付目录，测试使用隔离数据库和虚构记录。

## 证据

0.2.0已通过46项JVM与28项荣耀设备测试，APK散列及完整证据见 [实测报告](TEST_REPORT.md)。
保留首次34项JVM与24项设备基线，新增12项JVM及4项页面回归后完整重跑；截图复查修正侧栏系统留白后再次回归。
实际午夜、物理重启、TalkBack朗读及长期省电提醒没有因此自动变成已测。

配置覆盖测试采用 [Android 官方的 DeviceConfigurationOverride](https://developer.android.com/develop/ui/compose/testing/common-patterns)，只改变测试内容的可用尺寸，不改手机全局字号或显示设置。
