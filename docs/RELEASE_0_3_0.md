# 0.3.0：双栏桌面卡片和近7天交接

本轮针对用户明确指出的遗漏实现，不以0.2.0的其他优化替代本次需求。开源对照见 [Tasks.org及其他项目](OPEN_SOURCE_REVIEW_0_3_0.md)。

| 用户要求 | 0.3.0 实现 |
|---|---|
| 桌面卡片上下两栏 | 上栏为昨天／最近一条过去记录的交接目标，标明实际来源日期；下栏为今天的填写状态和摘要，点击整栏可进入今日三问 |
| 历史上半页日历，下半页近7天 | 默认近7个自然日，包含今天，逐日显示明日交接目标及交给哪一天；没有记录与目标为空分别提示 |
| 左上角三条横菜单 | 只在历史页显示，可选择全部记录、近3天、近7天、近30天，并标出当前范围 |
| 上滑隐藏日历 | 月历和交接卡片共用一条列表，上滑后月历自然移出视野，交接区域扩大 |
| 点横条恢复 | 范围标题处保留吸顶横条和“展开日历”，点击回到上方月历；也可点“收起日历”直接进入交接区域 |
| 今日页已经合适 | 保留原有三问、保存、交接查看和输入流程 |

“近7天”按 today-6 至 today 计算，不是最近七条记录，也不随正在浏览的日历月份而改变。
记录中的第三问交接给次日；不把空白日期或空目标替换为更早目标，不添加完成打卡、惩罚或新任务数据库。
全部记录保留所有已保存日期，包含用户主动预写的未来记录；搜索继续覆盖三个回答。

applicationId、同一Debug签名、Room schema1与JSON schema1保持一致，versionCode=3、versionName=0.3.0。
采用覆盖安装。实际构建、手机验证、截图及未测限制以 [测试报告](TEST_REPORT.md) 为准。

本轮54项JVM及37项荣耀90设备测试全部通过，0失败、0跳过。先检查了实际截图，再压缩日历普通字号留白，确保未滚动前首条目标已可见；另修复外部今日入口残留历史菜单。
