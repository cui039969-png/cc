# 隐私与安全报告 / Privacy and security reports

不要在公开 Issue 中附日记、导出文件、密钥、令牌或含个人资料的截图。使用合成样例描述问题。
Do not attach journals, exports, keys, tokens or personal screenshots to public issues. Describe issues with synthetic examples.

如 GitHub 的私密漏洞报告入口可用，请使用它；不可用时先仅公开最少信息请求私密沟通渠道，不公布可利用细节。
Use GitHub private vulnerability reporting when available. Otherwise, request a private channel using minimal public information, without publishing exploit details.
